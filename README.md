# coatless-shiny.github.io

Auto-built project index for [coatless-shiny](https://github.com/coatless-shiny), deployed to
[shiny.thecoatlessprofessor.com](https://shiny.thecoatlessprofessor.com/).

Source: [coatless/quarto-org-index](https://github.com/coatless/quarto-org-index).

Rebuilt daily by GitHub Actions plus on push to `main` and on
`repository_dispatch` event `refresh`.
